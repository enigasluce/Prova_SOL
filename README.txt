WEB APP POA, TEMPERATURA DI CELLA E VOC TODD-KARIN

Avvio locale:
1. Installare Python 3.10 o successivo.
2. Aprire un terminale nella cartella estratta.
3. Eseguire: pip install -r requirements.txt
4. Eseguire: streamlit run app.py

Il browser si aprira sulla pagina dell'applicazione.
L'implementazione termina alla sezione "Corrected Voc: tutte le temperature".
